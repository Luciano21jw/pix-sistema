# Pix Sistema - Detecção Automática de Pagamentos Nubank

Sistema de vendas com Pix que detecta automaticamente emails do Nubank e confirma pagamentos.

## 🚀 Como usar

1. **Publique seu Google Apps Script**
2. **Cole a URL do App Script no campo de configuração**
3. **Gere o Pix e aguarde a confirmação automática**

## 📱 Instalar no celular

Abra este site no Google Chrome e toque em "Instalar aplicativo"

## 🔧 Tecnologias

- HTML5 + CSS3 + JavaScript
- Google Apps Script (backend)
- PWA (instalação no celular)
- GitHub Pages (hospedagem)
