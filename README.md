# Pix Sistema

Sistema de vendas com Pix que detecta automaticamente emails do Nubank e confirma pagamentos .

## Como usar

1. Cole a URL do Google Apps Script no campo
2. Clique em "Testar Conexão"
3. Gere o Pix e aguarde a confirmação automática

## Instalar no celular

Abra no Google Chrome e toque em "Instalar aplicativo"

## Tecnologias

- HTML5 + CSS3 + JavaScript
- Google Apps Script
- PWA
